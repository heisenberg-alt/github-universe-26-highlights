The big picture

One vision, four threads

In his Universe post, Jay Parikh (EVP, CoreAI at Microsoft) describes GitHub's vision as “the most comprehensive software delivery system,” built for people and agents. Four threads run through everything announced.

Agents become the default workflow

In September 2026, more than 40% of PRs on GitHub began with an agent's first draft, up from 17% in March (Octoverse). The Copilot app, Projects, automations and Fusion model routing are GitHub's answer.

Review has to keep up

More agent output means more to read. Stacked PRs, a PR inbox and Copilot code review Max (public preview) go after the review bottleneck.

Security moves into the build loop

AI Scan, AI push protection, an npm package firewall and reachability analysis, plus a Security canvas in the Copilot app. All of them launched in public preview.

Reliability is the subtext

Pushes grew 4.9× in a year. GitHub is rebuilding its Git infrastructure while the service stays live and adding 4M CPU cores. Its own availability report admits a missed migration goal, and press coverage was skeptical.

Worth knowing: many of the new Copilot and security features are in public preview, and the headline performance numbers (Fusion's benchmark result, 35× write throughput) are GitHub's own claims. Each item's status is on the announcements page.
