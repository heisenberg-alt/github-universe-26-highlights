# GitHub Universe '26 Highlights

A static, unofficial recap of GitHub Universe 2026 (Oct 28–29, San Francisco): top sessions by topic, every announcement in order, and third-party takes. Plain HTML, CSS and a small `app.js` for progressive enhancements (theme toggle, session filter, scroll effects). There is no build step, and the content works without JavaScript.

## Files

- `index.html`: highlights, top sessions, outside voices
- `announcements.html`: all announcements, grouped by topic
- `assets/style.css`: GitHub Primer-style theme (dark by default, light via the toggle)
- `assets/app.js`: theme toggle, session filter tabs, animated hero graph, scroll effects


## Updating content

Everything is hand-written HTML. Announcement status badges follow the sources: `ga`, `preview`, `live`, or the default "Announced" when no status was given. Check the linked docs before upgrading a badge.
