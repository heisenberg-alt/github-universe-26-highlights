Copilot & agentsThe new app, model routing and cloud agents

  1. #1

    GitHub Copilot app

    Available

    An app for agent-driven delivery. Links your agents and tools across projects and covers non-code work like specs, design discussions and telemetry analysis. The docs give no GA or preview label for the app itself.

  2. #2

    Copilot Fusion

    GA

    Formerly Project HydraFusion. Pick Standard, High or Max effort; Fusion decides whether one model or several fits. Works in VS Code, Copilot CLI, the Copilot app and JetBrains. Standard is on every plan; High and Max need Pro+, Max, Business or Enterprise. No separate charge: you pay each model's standard rate, with 30% off model costs on paid plans through Nov 30, 2026. GitHub says Fusion Max came within two points of Opus 5.5 Max on the Artificial Analysis Coding Agent Index at half the cost and 40% less time.

  3. #3

    Copilot Projects

    Public preview

    A shared workspace for goals that span repos, or no repo at all. Runs parallel agent sessions in the background and returns results like PRs for review.

  4. #4

    Session continuity

    Announced

    Start and follow one cloud agent session across the Copilot app, VS Code, the CLI and the web. The agent keeps running in the cloud.

  5. #5

    Copilot automations

    Available

    Cloud-run workflows in a repo, started manually, by an event or on a schedule (issue triage, code review). They can learn from results and suggest improvements for you to approve. Private and internal repos only; each run uses AI credits and Actions minutes.

  6. #6

    Copilot connectors

    Public preview

    Authenticate once with services like Vercel, Cloudflare and Sentry. GitHub manages the MCP connection across the Copilot app, CLI, VS Code, web and code review. GitHub also names Cloudflare, Datadog and Figma as ecosystem partners.

  7. #7

    Computer use

    Public preview

    Copilot operates desktop apps that have no API, CLI or MCP support. Asks for approval first; organizations can disable it. macOS and Windows.

  8. #8

    Connected tools and image generation

    Announced

    In the Copilot app, use context from tools like Slack and Figma to research requests, draft specs or work on designs. Create and edit images from chat.

Review & workflowKeeping pull requests and issues moving

  1. #9

    Copilot code review Max

    Public preview

    The highest-effort review tier, for the most demanding PRs. GitHub says it posted the top F1 score on ReviewBench for high-severity issues. Docs put the average at about $10 per review (typically $1.50 to $25). Lite and Balanced remain for everyday reviews.

  2. #10

    Stacked pull requests

    Available

    Split large work into small, linked PRs, review each on its own, then merge the whole stack in one click. Start with the gh stack extension for GitHub CLI.

  3. #11

    Pull request inbox

    Available

    Scan open work, see its status and jump to the PRs that need you.

  4. #12

    Issue artifacts

    Public preview

    Attach plans, research and links to an issue so teammates see the reasoning behind the work. CLI commands need GitHub CLI 2.103.0 or later.

  5. #13

    Attach media from GitHub CLI

    Available

    A repeatable --attach flag embeds images and videos in issues, PRs and comments from your terminal.

SecurityFix risk while you build, and keep bad packages out

  1. #14

    Security extension for the Copilot app

    Public preview

    A Security canvas shows code you and your agents just wrote next to code scanning alerts. Ask Copilot to explain and fix findings, then review each change. Code scanning alerts only (not Dependabot or secret scanning), and fixes stay local until you commit.

  2. #15

    AI Scan

    Public preview

    On-demand whole-repo scanning in any language, with findings you can assign to Copilot. Also checks PRs in languages CodeQL doesn't cover, such as PHP and Terraform. The public preview status is stated for repository scanning.

  3. #16

    AI push protection

    Public preview

    Catches unstructured secrets like passwords that patterns miss and blocks them at push, whether a person or an agent wrote the code. Needs push protection and AI secret detection both on, plus Secret Protection or Advanced Security. Uses AI credits.

  4. #17

    Package firewall

    Public preview

    Stops malicious and risky npm packages before agents, runners or IDEs install them. npm only for now; Artifactory support is experimental.

  5. #18

    Reachability analysis

    Public preview

    Shows which vulnerable functions your JavaScript or TypeScript code actually calls, so you can prioritize Dependabot alerts. Needs a lock file and GitHub-hosted runners.

InfrastructureRebuilding the foundation for agent-scale load

  1. #19

    Capacity added this year

    Done

    4 million CPU cores, 160 PB of high-speed storage and 50 Tb/s of network capacity.

  2. #20

    New Git architecture

    In progress

    GitHub calls it its future architecture and is building it while the service keeps running: simpler primitives, storage decoupled from compute, minimal coordination, with authoritative data in Azure Blob Storage. In internal benchmarks it delivered up to 35× higher write throughput. No rollout dates given.

  3. #21

    Multi-region deployment in Azure

    In progress

    Migration in progress; GitHub expects to finish early next year. As of Oct 21, a copy of 99.99999% of repositories is in Azure and Azure serves about half of Git traffic. The busiest repos are held back by a roughly 25 ms round trip.

  4. Context

    GitHub availability report, September 2026

    GitHub's own report (Oct 14) says its principle is “availability, then capacity, then features.” As of Oct 7, 120 of 160 production services ran in Central US Azure, and the Sept 30 goal for moving every service was missed. The Register covers the outage backdrop.

PlansHow you buy Copilot

  1. #22

    Copilot included with GitHub Enterprise

    Available

    Enterprise customers get all Copilot features (app, code review, automations) without a separate subscription and pay for the AI credits they use. Available now through GitHub Sales; self-serve is coming. Existing Copilot Business and Enterprise plans can stay as they are.
