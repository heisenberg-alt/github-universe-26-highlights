Copilot & agentsThe new app, model routing and cloud agents

  1. #1

    GitHub Copilot app

    Available

    An app for agent-driven delivery. Links your agents and tools across projects and covers non-code work like specs, design discussions and telemetry analysis. The docs give no GA or preview label for the app itself.

  2. #2

    Copilot Fusion

    GA

    Formerly Project HydraFusion. Pick Standard, High or Max effort; Fusion decides whether one model or several fits. Works in VS Code, Copilot CLI, the Copilot app and JetBrains.

    More detailLess detail

    Standard is on every plan; High and Max need Pro+, Max, Business or Enterprise. No separate charge: you pay each model's standard rate, with 30% off model costs on paid plans through Nov 30, 2026. It runs tasks as a single model, a cascade (a lighter model drafts, a quality check escalates) or a critique (one drafts, another reviews). GitHub says Fusion Max came within two points of Opus 5.5 Max on the Artificial Analysis Coding Agent Index at half the cost and 40% less time. Artificial Analysis's own figures, per VentureBeat: $5.59 per task versus $11.42, index score 60 versus about 62. The time saving is GitHub-reported.

  3. #3

    Copilot Projects

    Public preview

    A shared workspace for goals that span repos, or no repo at all. Runs parallel agent sessions in the background and returns results like PRs for review.

  4. #4

    Session continuity

    Announced

    Start and follow one cloud agent session across the Copilot app, VS Code, the CLI, GitHub Mobile and the web, and continue sessions begun in Slack or Teams DMs. The agent keeps running in the cloud.

  5. #5

    Copilot automations

    Available

    Cloud-run workflows in a repo, started manually, by an event or on a schedule (issue triage, code review). They watch signals like whether people change the labels they apply or accept their review comments, then propose edits to their own prompts, tools or triggers; nothing changes until you accept.

    More detailLess detail

    Pro through Enterprise plans, private and internal repos only; each run uses AI credits and Actions minutes.

  6. #6

    Copilot connectors

    Public preview

    Authenticate once with services like Vercel, Cloudflare and Sentry. GitHub manages the MCP connection across the Copilot app, CLI, VS Code, web and code review.

    More detailLess detail

    GitHub also names Cloudflare, Datadog and Figma as ecosystem partners.

  7. #7

    Computer use

    Public preview

    Copilot operates desktop apps that have no API, CLI or MCP support. Asks for approval first; organizations can disable it. macOS and Windows.

  8. #8

    Fusion with local models

    Experimental preview

    Opt-in experimental routing between local and cloud models in the CLI, Copilot app and VS Code, using MAI Code 1.1 Flash on Windows ML or a bring-your-own model such as Qwen3.8 Flash Next.

    More detailLess detail

    Routing decisions are still made in the cloud, so sessions are not offline.

  9. #9

    Connected tools and image generation

    Announced

    In the Copilot app, use context from tools like Slack and Figma to research requests, draft specs or work on designs. Create and edit images from chat.

  10. Related

    Microsoft Copilot harness in Foundry Agent Service

    Public preview

    Microsoft opened the agent runtime behind Copilot to outside developers on Oct 28. No charge before Dec 1, then consumption billing. Tech Times reported it as announced at Universe by GitHub's CTO; Microsoft's own post does not mention Universe, so it is listed here as related rather than as a GitHub announcement.

Review & workflowKeeping pull requests and issues moving

  1. #10

    Copilot code review Max

    Public preview

    The highest-effort review tier. Several independent review agents on models from different providers run, then an aggregation agent reconciles their findings into one review.

    More detailLess detail

    GitHub says it posted the top F1 score on ReviewBench for high-severity issues. Docs put the average at about $10 per review (typically $1.50 to $25). Set it per PR, or as a default with an admin cap. Lite and Balanced remain for everyday reviews.

  2. #11

    Copilot approvals

    GA

    Copilot can approve a PR, and its approval counts toward required approvals. Off by default; admins enable it at enterprise, organization or repo level, and repo admins can limit which file paths Copilot may approve.

    More detailLess detail

    Like a human approval, it is dismissed when new commits are pushed. Pro through Enterprise plans.

  3. #12

    Stacked pull requests

    Available

    Split large work into small, linked PRs, review each on its own, then merge the whole stack in one click. Start with the gh stack extension for GitHub CLI.

  4. #13

    Pull request inbox

    Available

    Scan open work, see its status and jump to the PRs that need you.

  5. #14

    Issue artifacts

    Public preview

    Attach plans, research and links to an issue so teammates see the reasoning behind the work. CLI commands need GitHub CLI 2.103.0 or later.

  6. #15

    Attach media from GitHub CLI

    Available

    A repeatable --attach flag embeds images and videos in issues, PRs and comments from your terminal.

In your editorVS Code, JetBrains and your phone

  1. #16

    Agent Host and phone control

    Announced

    In VS Code, agent sessions run independently of editor windows, or on a remote machine over SSH or dev tunnels. GitHub Mobile can monitor, steer or start tasks on your dev machine.

    More detailLess detail

    An open Agent Host Protocol lets you build your own client (libraries for TypeScript, Rust, Go, Kotlin and Swift).

  2. #17

    Copilot harness is the default

    Available

    The Microsoft Copilot harness, built on the Copilot SDK, is now the default for new sessions in VS Code and JetBrains, aiming for consistent behavior across the editor, CLI and Copilot app.

  3. #18

    Compare model results

    Public preview

    Run models and harnesses in parallel in VS Code and view results side by side. A Judge model can recommend one, and Synthesize merges ideas from several.

  4. #19

    Marketplace customizations and plugin controls

    Public preview

    A Browse page for skills, MCP servers and plugins, enabled by default in preview. Business and Enterprise admins can require or block plugins, add marketplaces and limit installs to approved sources.

    More detailLess detail

    Connectors (Slack, Notion and Microsoft Learn context) are also in preview on all plans.

  5. #20

    JetBrains: local sandboxes and next edit suggestions

    GA

    Local sandboxes (Copilot-launched tools run on your machine with limited file, network and credential access) and next edit suggestions are generally available in JetBrains IDEs. Fusion is rolling out there too, replacing the Auto option.

SecurityFix risk while you build, and keep bad packages out

  1. #21

    Security extension for the Copilot app

    Public preview

    A Security canvas shows code you and your agents just wrote next to code scanning alerts. Ask Copilot to explain and fix findings, then review each change.

    More detailLess detail

    Code scanning alerts only (not Dependabot or secret scanning), and fixes stay local until you commit.

  2. #22

    AI Scan

    Public preview

    On-demand whole-repo scanning in any language, with findings you can assign to Copilot. Also checks PRs in languages CodeQL doesn't cover, such as PHP and Terraform. The public preview status is stated for repository scanning.

  3. #23

    AI push protection

    Public preview

    Catches unstructured secrets like passwords that patterns miss and blocks them at push, whether a person or an agent wrote the code.

    More detailLess detail

    Needs push protection and AI secret detection both on, plus Secret Protection or Advanced Security. Uses AI credits.

  4. #24

    Package firewall

    Public preview

    Stops malicious and risky npm packages before agents, runners or IDEs install them. npm only for now; Artifactory support is experimental.

  5. #25

    Reachability analysis

    Public preview

    Shows which vulnerable functions your JavaScript or TypeScript code actually calls, so you can prioritize Dependabot alerts. Needs a lock file and GitHub-hosted runners.

InfrastructureRebuilding the foundation for agent-scale load

  1. #26

    Capacity added this year

    Done

    4 million CPU cores, 160 PB of high-speed storage and 50 Tb/s of network capacity.

  2. #27

    New Git architecture

    In progress

    GitHub calls it its future architecture and is building it while the service keeps running: simpler primitives, storage decoupled from compute, minimal coordination, with authoritative data in Azure Blob Storage.

    More detailLess detail

    In internal benchmarks it delivered up to 35× higher write throughput. No rollout dates given.

  3. #28

    Multi-region deployment in Azure

    In progress

    Migration in progress; GitHub expects to finish early next year. As of Oct 21, a copy of 99.99999% of repositories is in Azure and Azure serves about half of Git traffic. The busiest repos are held back by a roughly 25 ms round trip.

  4. Context

    GitHub availability report, September 2026

    GitHub's own report (Oct 14) says its principle is “availability, then capacity, then features.” As of Oct 7, 120 of 160 production services ran in Central US Azure, and the Sept 30 goal for moving every service was missed. The Register covers the outage backdrop.

PlansHow you buy Copilot

  1. #29

    Copilot included with GitHub Enterprise

    Available

    Enterprise customers get all Copilot features (app, code review, automations) without a separate subscription and pay for the AI credits they use.

    More detailLess detail

    Available now through GitHub Sales; self-serve is coming. Existing Copilot Business and Enterprise plans can stay as they are.
